## Más allá de los modelos

Mientras los modelos de lenguaje acaparan titulares, el ecosistema que los rodea evoluciona con tendencias igualmente transformadoras. Desde protocolos que conectan modelos con herramientas hasta agentes que actúan de forma autónoma.

<Callout type="info">
El modelo es solo una pieza del puzle. La verdadera revolución está en cómo los modelos se conectan, despliegan y aplican en el mundo real.
</Callout>

## Agentes autónomos

La tendencia más importante del ecosistema: pasar de modelos que responden preguntas a sistemas que ejecutan tareas.

### Evolución

1. **2023:** chatbots conversacionales
2. **2024:** agentes simples con herramientas
3. **2025:** agentes multi-paso con planificación
4. **2026:** sistemas multi-agente coordinados

### Plataformas destacadas

- **Claude Code:** agente de terminal que lee, escribe y ejecuta código
- **OpenHands:** alternativa de código abierto a Devin
- **CrewAI:** marco de trabajo para orquestar equipos de agentes
- **LangGraph:** construcción de flujos de agentes complejos

## Model Context Protocol (MCP)

Anthropic introdujo MCP como un estándar abierto para conectar modelos de lenguaje con herramientas externas.

### ¿Por qué es importante?

- **Estandarización:** un solo protocolo para conectar cualquier herramienta
- **Seguridad:** control granular sobre qué puede acceder el modelo
- **Extensibilidad:** cualquier servicio puede implementar un servidor MCP
- **Adopción:** soportado por Claude, Cursor y creciente comunidad

### Ejemplos de uso

- Conectar un modelo a una base de datos SQL
- Acceder a APIs de servicios externos (Slack, GitHub, Notion)
- Leer y escribir archivos del sistema local
- Navegación web automatizada

<Callout type="tip">
MCP está llamado a ser lo que HTTP fue para la web: un estándar que permite la interoperabilidad. Si trabajas con agentes IA, MCP es una de las tecnologías más importantes que puedes aprender.
</Callout>

## IA en el navegador

La ejecución de modelos directamente en el navegador está democratizando el acceso:

- **WebLLM:** ejecuta modelos como Llama y Gemma en el navegador
- **Transformers.js:** inferencia de transformers directamente en JavaScript
- **ONNX Runtime Web:** ejecución optimizada en el navegador
- **Chrome Built-in AI:** APIs de IA nativas en Chrome

### Ventajas

- Sin necesidad de servidor
- Privacidad total (datos locales)
- Sin latencia de red
- Gratuito para la persona usuaria
- Funciona offline

## Código abierto y democratización

El ecosistema de código abierto de IA ha madurado enormemente:

- **Modelos:** Llama 4, Mistral, Gemma, Qwen, DeepSeek
- **Marcos de trabajo:** LangChain, Haystack, DSPy, LlamaIndex
- **Infraestructura:** vLLM, Ollama, TGI, llama.cpp
- **Conjuntos de datos:** Hugging Face lidera con millones de conjuntos de datos

<Callout type="info">
El ecosistema de código abierto está cerrando la brecha con los modelos propietarios. Para finales de 2026 se espera que modelos abiertos igualen o superen a GPT-4 en la mayoría de tareas.
</Callout>

## Otras tendencias relevantes

**IA Generativa de Vídeo**
Runway Gen-4, Sora y Veo 2 están llevando la generación de vídeo a nuevos niveles de realismo y control.

**Razonamiento y cadenas de pensamiento**
Modelos que explicitan su proceso de razonamiento (o1 de OpenAI, Gemini Thinking, Claude Extended Thinking).

**Personalización masiva**
El ajuste fino y RAG hacen posible crear asistentes especializados para cada persona usuaria u organización.

**Voz a voz**
Modelos que procesan audio directamente sin transcripción intermedia, permitiendo conversaciones más naturales.
