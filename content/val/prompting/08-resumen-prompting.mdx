## El que has après

En aquest bloc has recorregut el camí complet de l'enginyeria de prompt:

### Els fonaments
- **Què és un prompt**: La instrucció que li dones a la IA
- **Per què importa**: La qualitat de la teua entrada determina la qualitat de l'eixida
- **Què és l'enginyeria de prompt**: L'art de dissenyar instruccions efectives

### L'anatomia d'un bon prompt
1. **Rol** - Qui és la IA
2. **Context** - Informació rellevant
3. **Tasca** - Què vols exactament
4. **Format** - Com vols la resposta
5. **Restriccions** - Límits i condicions
6. **Exemples** - Mostres del resultat esperat

### Les tècniques
| Tècnica | Per a què serveix |
|---------|---------------|
| Zero-shot | Tasques simples sense exemples |
| Few-shot | Tasques amb patró definit |
| Role | Perspectiva especialitzada |
| Chain-of-Thought | Raonament pas a pas |
| Tree-of-Thought | Explorar múltiples solucions |
| ReAct | Raonar + buscar informació |

### Adaptació per model
- **ChatGPT**: Directe, versàtil, tot terreny
- **Claude**: Profund, matisat, analític
- **Gemini**: Factual, concís, amb fonts

## Les 10 regles d'or

1. **Sigues específic**: Un prompt específic dona una resposta específica
2. **Dóna context**: La IA no sap la teua situació a menys que l'hi expliques
3. **Defineix el format**: Taules, llistes, paràgrafs: digues-ho explícitament
4. **Itera**: El teu primer prompt no serà el millor. Refina, prova, millora
5. **Usa rols**: Assignar un rol millora dràsticament la qualitat
6. **Posa restriccions**: Límits d'extensió, to, audiència
7. **Afig exemples**: El few-shot és sorprenentment efectiu
8. **Demana pas a pas**: Per a problemes complexos, demana raonament
9. **Adapta al model**: No és el mateix ChatGPT que Claude o Gemini
10. **Verifica sempre**: La IA s'equivoca. Confirma dades importants

## Errors comuns que has d'evitar

### ❌ El prompt vague
"Escriu alguna cosa sobre IA"

### ❌ El prompt sense context
"Tradueix això a l'anglés" (sense especificar formal/informal)

### ❌ El prompt sense restriccions
"Dóna'm idees per al meu negoci" (sense límit de quantitat ni enfocament)

### ❌ El prompt que assumeix coneixement
"Explica'm els transformers" (sense saber si qui ho consulta coneix l'aprenentatge profund)

### ❌ El prompt que no itera
Usar el primer resultat sense demanar millores

## La teua llista de comprovació diària

Abans d'enviar un prompt important, revisa aquesta llista:

- [ ] El prompt té un objectiu clar?
- [ ] He donat suficient context?
- [ ] El format d'eixida està definit?
- [ ] Les restriccions són adequades?
- [ ] He considerat quin model usar?
- [ ] Estic disposat a iterar si no és perfecte?

## El futur del prompting

L'enginyeria de prompt està evolucionant ràpidament:

### Tendències actuals
- **Agents autònoms**: La IA fa múltiples passos sense intervenció
- **Multimodal**: Prompts que combinen text, imatges i àudio
- **Personalització**: Prompts que s'adapten a qui els usa
- **Automatització**: Prompts que generen altres prompts

### Habilitats complementàries
- **RAG (Retrieval-Augmented Generation)**: Combinar prompts amb cerca
- **Ajust fi**: Entrenar models amb les teues dades
- **Avaluació**: Mesurar la qualitat de les respostes

<Callout type="tip">
L'enginyeria de prompt no és una moda passatgera. És una habilitat fonamental per a qualsevol professional que vulga aprofitar la IA. Com millor et comuniques amb la IA, més valor n'obtindràs.
</Callout>
