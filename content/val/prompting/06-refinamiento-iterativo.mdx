## El primer prompt quasi mai no és el millor

Fins i tot els experts en enginyeria de prompt rarament encerten al primer intent. La clau està en **iterar**: provar, avaluar, ajustar i repetir.

## El cicle de refinament

```
Escriure prompt → Provar → Avaluar resultat → Identificar millora → Ajustar prompt → Repetir
```

## Pas 1: Escriu un prompt inicial

No busques la perfecció. Escriu alguna cosa que funcione com a punt de partida.

**Prompt inicial:**
```
Give me tips to improve my productivity
```

**Resultat típic:** Consells genèrics que ja has sentit mil vegades.

## Pas 2: Identifica què falta

Pregunta't:
- Va ser massa vague? → Afig especificitat
- Va faltar context? → Afig la teua situació
- El format no era útil? → Especifica el format
- Massa llarg? → Simplifica

**Problema identificat:** El prompt és massa vague. No especifica la meua situació ni el format.

## Pas 3: Ajusta i prova de nou

**Prompt millorat:**
```
I am a freelance developer who works from home. Tell me 5 specific productivity techniques for my situation. For each technique, include: name, how to apply it and expected benefit. In table format.
```

**Resultat:** Molt més útil i aplicable.

## Pas 4: Refina més

Si encara no és perfecte, segueix iterant:

**Prompt final:**
```
I am a freelance developer who tends to get distracted by social media. I work 8 hours a day from home. I need proven productivity techniques for:

1. Starting the day with focus (first hour)
2. Staying focused during 2-hour blocks
3. Managing post-lunch mental fatigue

For each technique: name, concrete steps, time needed and how to measure results.
```

## Tècniques de refinament específiques

### 1. Afig context progressivament
```
Prompt 1: "Write a sales email"
Prompt 2: "Write a sales email for project management software"
Prompt 3: "Write a sales email for project management software aimed at Spanish SMEs, highlighting time savings"
```

### 2. Demana crítica a la IA
Demanes a la IA que avalue la seua pròpia resposta o el teu prompt:
```
How would I improve this prompt to get a more specific result? Give me 3 concrete suggestions.
```

### 3. Usa el resultat com a nou prompt
Agafa la resposta de la IA i usa-la com a base per a una nova iteració:
```
Take the text you just generated and make it 40% shorter, keeping the key points.
```

### 4. Preguntar abans de respondre
```
Before answering, ask me questions to better understand what I need. Then answer based on my answers.
```

## Exemple complet de refinament

**Iteració 1:**
```
Create an AI learning plan
```
→ Massa genèric

**Iteració 2:**
```
I am an entrepreneur with no technical background. I want to learn AI to apply it to my e-commerce business. Create a 3-month plan.
```
→ Millor, però encara sense detalls

**Iteració 3:**
```
I am a fashion e-commerce entrepreneur with no technical background. I want a 3-month AI learning plan, 5 hours/week. Objectives:
- Month 1: Understand what AI can do for my business
- Month 2: Try AI tools for e-commerce
- Month 3: Implement at least 1 AI automation
For each month: resources, practical exercises and success metrics.
```
→ Específic, mesurable, accionable

## Llista de comprovació del refinament

Abans de considerar un prompt "acabat", verifica:

- [ ] Té un rol clar?
- [ ] El context és suficient?
- [ ] La tasca és específica?
- [ ] El format d'eixida està definit?
- [ ] Hi ha restriccions útils?
- [ ] El to és l'adequat?
- [ ] L'extensió és la correcta?
- [ ] Necessita exemples (few-shot)?
