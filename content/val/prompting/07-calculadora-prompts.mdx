## Construeix el teu prompt ideal

Aquesta eina et guia pas a pas per a construir prompts efectius. Selecciona les opcions que millor s'adapten a la teua necessitat i genera un prompt a punt per a usar.

## Com usar la calculadora

1. **Descriu la teua tasca**: Què necessites que faça la IA?
2. **Tria el rol**: Quina perspectiva vols que adopte?
3. **Selecciona el format**: Com vols la resposta?
4. **Afig restriccions**: To, extensió, audiència
5. **Copia el prompt**: El prompt generat està a punt per a usar

## Consells per a millors resultats

### Sigues específic en la tasca
"Escriu un correu" és vague. "Escriu un correu de seguiment per a un client que no ha comprat en 3 mesos" és específic.

### El rol correcte
Si no estàs segur del rol, pensa en quin professional faria millor aquesta tasca. Un advocat? Un professor? Un periodista? Un cuiner?

### Format segons el mitjà
- **Correu**: Assumpte + cos + comiat
- **Article**: Títol + introducció + cos + conclusió
- **Anàlisi**: Dades + interpretació + recomanació
- **Codi**: Explicació + codi + exemples d'ús

## Combinació amb altres tècniques

La calculadora et dona un prompt base. Pots millorar-lo combinant-lo amb tècniques avançades:

### Afig Chain-of-Thought
```
[Generated prompt] + "Think step by step before answering"
```

### Afig exemples (few-shot)
```
[Generated prompt] + "Here is an example of the format I want: [example]"
```

### Afig iteració
```
[Generated prompt] + "If something is not clear, ask me before answering"
```
