## De les eines als projectes

Has explorat cada eina del laboratori per separat. Ara és el moment de combinar-les per a resoldre problemes reals. Els projectes integrats et preparen per a aplicar el que has aprés en situacions del món real.

<Callout type="info">
El veritable domini de la IA no està a usar bé una eina, sinó a saber quina eina usar per a cada problema i com combinar-les per a obtindre resultats superiors.
</Callout>

## Projecte 1: Assistent educatiu complet

### Objectiu

Crear un sistema de suport a l'aprenentatge que combine diverses capacitats.

### Eines del laboratori

1. **Chat IA:** investiga el tema i genera contingut base
2. **Entorn de Prompts:** dissenya prompts optimitzats per a cada tasca educativa
3. **Flux d'Agents:** construeix un flux que reba preguntes i torne respostes contextualitzades
4. **Comparador:** selecciona el millor model per a cada tipus de tasca educativa
5. **Simulador de Tokens:** estima costos abans d'escalar la solució

### Flux de treball

1. Usa el Chat IA per a explorar el tema educatiu
2. Dissenya prompts a l'Entorn de Prompts per a diferents rols (professor, tutor, avaluador)
3. Construeix un flux a Flux d'Agents que encadene les respostes
4. Compara models per a triar el més adequat
5. Simula el consum de tokens per a planificar l'ús

## Projecte 2: Analitzador de documents

### Objectiu

Sistema que processa documents llargs, extrau informació clau i genera informes.

### Flux suggerit

1. **Entorn de Prompts:** dissenya el prompt d'extracció (rol=analista, format=informe)
2. **Flux d'Agents:** encadena Input → LLM (extraure) → LLM (estructurar) → Output
3. **Simulador de Tokens:** calcula el cost de processar documents grans
4. **Comparador:** avalua quin model gestiona millor documents extensos

## Projecte 3: Comparativa d'eines d'IA

### Objectiu

Investigació completa comparant eines per a un cas d'ús específic.

### Flux suggerit

1. **Chat IA:** investiga les eines disponibles per al teu cas d'ús
2. **Comparador:** selecciona fins a 4 eines i compara-les
3. **Entorn de Prompts:** genera un informe de recomanació
4. **Simulador de Tokens:** estima costos de cada opció

## Projecte 4: Automatització de contingut

### Objectiu

Flux que genere, revise i formate contingut de manera automatitzada.

### Exemple a Flux d'Agents

```
Input (tema)
  → LLM (generar borrador)
  → LLM (revisar y corregir)
  → Tool (formatear)
  → Output (contenido final)
```

<Callout type="tip">
No intentes usar totes les eines en cada projecte. Selecciona les que aporten valor real a l'objectiu. Un projecte amb 2 eines ben usades és millor que un amb 5 eines mal integrades.
</Callout>

## Metodologia per als teus projectes

### Fase 1: Definició

- Quin problema resol?
- Qui usarà la solució?
- Quines eines del laboratori són rellevants?

### Fase 2: Prototipatge

- Prova cada component per separat
- Ajusta prompts i configuracions
- Valida resultats parcials

### Fase 3: Integració

- Connecta els components
- Prova el flux complet
- Identifica colls d'ampolla

### Fase 4: Optimització

- Refina prompts segons els resultats
- Ajusta l'ordre dels nodes
- Optimitza el consum de tokens

### Fase 5: Documentació

- Anota les configuracions que van funcionar
- Crea una guia d'ús
- Comparteix els teus aprenentatges

## Repte final

Dissenya, implementa i documenta un projecte integrat que:

1. Use almenys 3 eines del laboratori
2. Resolga un problema real del teu àmbit
3. Incloga un flux d'almenys 3 nodes a Flux d'Agents
4. Documente les decisions de disseny i els resultats
