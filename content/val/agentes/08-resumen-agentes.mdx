## Resum del bloc

Hem recorregut el fascinant món dels **agents d'IA i l'automatització**. Repassem l'essencial:

### Conceptes fonamentals

Un agent d'IA és un sistema que **percep, raona i actua** per a aconseguir un objectiu. Combina un LLM com a cervell amb eines, memòria i autonomia.

### Tipus d'agents

| Tipus | Clau | Ús principal |
|------|-------|---------------|
| Reactiu | Sense memòria | Tasques simples i immediates |
| Amb memòria | Estat persistent | Assistents i chatbots |
| Autònom | Planificació en diversos passos | Automatització complexa |
| Multiagent | Rols especialitzats | Projectes empresarials |

### MCP (Model Context Protocol)

L'estàndard obert per a connectar agents amb eines externes. Client ↔ Servidor, amb descobriment automàtic i seguretat per aïllament.

### RAG avançat

Arquitectura que combina la **recuperació d'informació** amb la generació de text. Tècniques clau: chunking semàntic, multi-consulta, reordenació de resultats i RAG contextual.

### Automatització de fluxos

Plataformes com **Make, Zapier i n8n** permeten integrar IA en processos automatitzats sense necessitat de programar des de zero.

### Marcs de treball per a agents

| Marc de treball | Ideal per a |
|------------------|------------|
| LangChain | Aplicacions generals amb LLMs |
| CrewAI | Sistemes multiagent |
| Haystack | Sistemes RAG |
| Dify | Prototipatge visual |

### Exemples pràctics

Els agents estan transformant: investigació acadèmica, suport tècnic, anàlisi de xarxes socials, desenvolupament de programari i gestió de projectes.

## Glossari del bloc

| Terme | Definició |
|---------|------------|
| **Agent** | Sistema que percep, raona i actua per a aconseguir un objectiu |
| **MCP** | Protocol estàndard per a connectar LLMs amb eines |
| **RAG** | Arquitectura que combina cerca + generació de text |
| **ReAct** | Patró que alterna raonament i acció |
| **Embedding** | Representació vectorial de text per a la cerca semàntica |
| **LLM** | Model de llenguatge gran, cervell de l'agent |
| **Tool** | Funció externa que un agent pot executar |
| **Chunk** | Fragment de document usat en RAG |
| **Multiagent** | Sistema amb múltiples agents especialitzats |
| **Persona en el circuit** | Supervisió humana en decisions crítiques |
