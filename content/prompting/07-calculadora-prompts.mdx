## Construye tu prompt ideal

Esta herramienta te guía paso a paso para construir prompts efectivos. Selecciona las opciones que mejor se adapten a tu necesidad y genera un prompt listo para usar.

## Cómo usar la calculadora

1. **Describe tu tarea**: ¿Qué necesitas que haga la IA?
2. **Elige el rol**: ¿Qué perspectiva quieres que adopte?
3. **Selecciona el formato**: ¿Cómo quieres la respuesta?
4. **Añade restricciones**: Tono, extensión, audiencia
5. **Copia el prompt**: El prompt generado está listo para usar

## Consejos para mejores resultados

### Sé específico en la tarea
"Escribe un correo" es vago. "Escribe un correo de seguimiento para un cliente que no ha comprado en 3 meses" es específico.

### El rol correcto
Si no estás seguro del rol, piensa en qué profesional haría mejor esa tarea. ¿Un abogado? ¿Un profesor? ¿Un periodista? ¿Un chef?

### Formato según el medio
- **Correo**: Asunto + cuerpo + despedida
- **Artículo**: Título + introducción + cuerpo + conclusión
- **Análisis**: Datos + interpretación + recomendación
- **Código**: Explicación + código + ejemplos de uso

## Combinación con otras técnicas

La calculadora te da un prompt base. Puedes mejorarlo combinándolo con técnicas avanzadas:

### Añadir Chain-of-Thought
```
[Prompt generado] + "Piensa paso a paso antes de responder"
```

### Añadir ejemplos (few-shot)
```
[Prompt generado] + "Aquí tienes un ejemplo del formato que quiero: [ejemplo]"
```

### Añadir iteración
```
[Prompt generado] + "Si algo no está claro, pregúntame antes de responder"
```

<Callout type="tip">
La calculadora es un excelente punto de partida. A medida que ganes experiencia, aprenderás a ajustar y personalizar los prompts para obtener resultados aún mejores.
</Callout>
