## No todos los modelos responden igual

Cada modelo de IA tiene su propia "personalidad", fortalezas y limitaciones. El mismo prompt puede dar resultados muy diferentes en ChatGPT, Claude o Gemini.

## ChatGPT (OpenAI)

**Personalidad:** Versátil, directo, generalista.

### Funciona mejor con:
- Instrucciones claras y directas
- Tareas paso a paso
- Formato estructurado

### Ejemplo efectivo:
```
Eres un asistente de investigación. Analiza estos datos de ventas del último trimestre y genera un informe ejecutivo de 3 secciones: resumen, tendencias y recomendaciones. Usa tono profesional.
```

### A evitar:
- Instrucciones muy abiertas (vagas)
- Que le pidas "sé creativo" sin dirección

## Claude (Anthropic)

**Personalidad:** Analítico, matizado, cuidadoso.

### Funciona mejor con:
- Preguntas que requieren matices
- Análisis profundos de documentos
- Tareas que necesitan precisión

### Ejemplo efectivo:
```
Analiza este documento de 20 páginas y extrae los 5 argumentos principales a favor y en contra de la propuesta. Para cada argumento, proporciona evidencia textual del documento y evalúa su solidez del 1 al 5.
```

### A evitar:
- Instrucciones demasiado directas (Claude es más reflexivo)
- Prompts muy cortos sin contexto

### Diferencias clave:
Claude tiende a ser más cauto y matizado. Si necesitas respuestas más largas y detalladas, dale más espacio en el prompt.

## Gemini (Google)

**Personalidad:** Conciso, factual, integrado con Google.

### Funciona mejor con:
- Preguntas factuales y actualizadas
- Análisis de documentos masivos
- Integración con Google Workspace

### Ejemplo efectivo:
```
Basado en las tendencias actuales de 2026, dime cuáles son las 3 innovaciones más importantes en IA generativa. Incluye fuentes y fechas.
```

### A evitar:
- Preguntas que requieren opinión subjetiva (Gemini es más factual)
- Instrucciones largas sin estructura

## Comparativa de estilos

| Aspecto | ChatGPT | Claude | Gemini |
|---------|---------|--------|--------|
| Estilo de respuesta | Directo, versátil | Matizado, profundo | Conciso, factual |
| Longitud ideal | Media | Larga | Corta-media |
| Tono | Neutral-profesional | Cuidadoso-formal | Directo-informativo |
| Creatividad | Alta | Media | Baja-media |
| Estructura | Le gusta seguir formatos | Prefiere texto fluido | Responde con listas |

## Cómo adaptar tus prompts

### Para ChatGPT
```
[Instrucción clara] → [Formato específico] → [Ejemplo opcional]
```

### Para Claude
```
[Contexto detallado] → [Pregunta matizada] → [Solicitud de análisis]
```

### Para Gemini
```
[Pregunta factual] → [Formato de respuesta] → [Solicitud de fuentes]
```

## Ejemplo práctico: La misma petición en 3 modelos

**Tarea:** Explicar la computación cuántica a un principiante

**Para ChatGPT:**
```
Eres un divulgador científico. Explica la computación cuántica a alguien que no sabe nada del tema. Usa 3 analogías del mundo real y mantenlo en menos de 200 palabras.
```

**Para Claude:**
```
Necesito explicar la computación cuántica a mi abuela de 70 años que nunca ha oído hablar de ella. Quiero que la explicación sea clara, use analogías cotidianas, destaque por qué es importante sin asustar, y termine con una frase que invite a la curiosidad.
```

**Para Gemini:**
```
Explica la computación cuántica en términos simples. Dame 3 puntos clave y 1 analogía. Mínimo de jerga técnica. Extensión máxima: 150 palabras.
```

<Callout type="tip">
La mejor estrategia no es aprender a usar un solo modelo, sino saber cuál funciona mejor para cada tarea y adaptar tu prompt en consecuencia.
</Callout>
