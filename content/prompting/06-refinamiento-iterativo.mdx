## El primer prompt casi nunca es el mejor

Incluso los expertos en ingeniería de prompt rara vez aciertan al primer intento. La clave está en **iterar**: probar, evaluar, ajustar y repetir.

## El ciclo de refinamiento

```
Escribir prompt → Probar → Evaluar resultado → Identificar mejora → Ajustar prompt → Repetir
```

## Paso 1: Escribe un prompt inicial

No busques la perfección. Escribe algo que funcione como punto de partida.

**Prompt inicial:**
```
Dame consejos para mejorar mi productividad
```

**Resultado típico:** Consejos genéricos que ya has oído mil veces.

## Paso 2: Identifica qué falta

Pregúntate:
- ¿Fue muy vago? → Añade especificidad
- ¿Faltó contexto? → Añade tu situación
- ¿El formato no era útil? → Especifica el formato
- ¿Demasiado largo? → Simplifica

**Problema identificado:** El prompt es demasiado vago. No especifica mi situación ni el formato.

## Paso 3: Ajusta y prueba de nuevo

**Prompt mejorado:**
```
Soy un desarrollador freelance que trabaja desde casa. Dime 5 técnicas de productividad específicas para mi situación. Para cada técnica, incluye: nombre, cómo aplicarla y beneficio esperado. En formato tabla.
```

**Resultado:** Mucho más útil y aplicable.

## Paso 4: Refina más

Si aún no es perfecto, sigue iterando:

**Prompt final:**
```
Soy un desarrollador freelance con tendencia a distraerme con redes sociales. Trabajo 8 horas al día desde casa. Necesito técnicas de productividad probadas para:

1. Empezar el día con enfoque (primera hora)
2. Mantener concentración durante bloques de 2 horas
3. Gestionar el cansancio mental post-almuerzo

Para cada técnica: nombre, pasos concretos, tiempo necesario y cómo medir resultados.
```

## Técnicas de refinamiento específicas

### 1. Añadir contexto progresivamente
```
Prompt 1: "Escribe un email de ventas"
Prompt 2: "Escribe un email de ventas para un software de gestión de proyectos"
Prompt 3: "Escribe un email de ventas para un software de gestión de proyectos dirigido a PYMEs españolas, destacando ahorro de tiempo"
```

### 2. Pedir crítica a la IA
Pídele a la IA que evalúe su propia respuesta o tu prompt:
```
¿Cómo mejoraría este prompt para obtener un resultado más específico? Dame 3 sugerencias concretas.
```

### 3. Usar el resultado como nuevo prompt
Toma la respuesta de la IA y úsala como base para una nueva iteración:
```
Toma el texto que acabas de generar y hazlo un 40% más corto, manteniendo los puntos clave.
```

### 4. Preguntar antes de responder
```
Antes de responder, hazme preguntas para entender mejor lo que necesito. Luego responde con base en mis respuestas.
```

## Ejemplo completo de refinamiento

**Iteración 1:**
```
Crea un plan de aprendizaje de IA
```
→ Demasiado genérico

**Iteración 2:**
```
Soy un emprendedor sin experiencia técnica. Quiero aprender IA para aplicarlo a mi negocio de e-commerce. Crea un plan de 3 meses.
```
→ Mejor, pero aún sin detalles

**Iteración 3:**
```
Soy emprendedor de e-commerce de moda, sin experiencia técnica. Quiero un plan de aprendizaje de IA de 3 meses, 5 horas/semana. Objetivos:
- Mes 1: Entender qué IA puede hacer por mi negocio
- Mes 2: Probar herramientas de IA para e-commerce
- Mes 3: Implementar al menos 1 automatización con IA
Para cada mes: recursos, ejercicios prácticos y métricas de éxito.
```
→ Específico, medible, accionable

## Lista de comprobación del refinamiento

Antes de considerar un prompt "terminado", verifica:

- [ ] ¿Tiene un rol claro?
- [ ] ¿El contexto es suficiente?
- [ ] ¿La tarea es específica?
- [ ] ¿El formato de salida está definido?
- [ ] ¿Hay restricciones útiles?
- [ ] ¿El tono es el adecuado?
- [ ] ¿La extensión es la correcta?
- [ ] ¿Necesita ejemplos (few-shot)?
