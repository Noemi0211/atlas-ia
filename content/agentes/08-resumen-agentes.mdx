## Resumen del bloque

Hemos recorrido el fascinante mundo de los **agentes de IA y la automatización**. Repasemos lo esencial:

### Conceptos fundamentales

Un agente de IA es un sistema que **percibe, razona y actúa** para lograr un objetivo. Combina un LLM como cerebro con herramientas, memoria y autonomía.

### Tipos de agentes

| Tipo | Clave | Uso principal |
|------|-------|---------------|
| Reactivo | Sin memoria | Tareas simples e inmediatas |
| Con memoria | Estado persistente | Asistentes y chatbots |
| Autónomo | Planificación multi-paso | Automatización compleja |
| Multiagente | Roles especializados | Proyectos empresariales |

### MCP (Model Context Protocol)

El estándar abierto para conectar agentes con herramientas externas. Cliente ↔ Servidor, con descubrimiento automático y seguridad por aislamiento.

### RAG avanzado

Arquitectura que combina **recuperación de información** con generación de texto. Técnicas clave: chunking semántico, multi-consulta, reordenación de resultados y RAG contextual.

### Automatización de flujos

Plataformas como **Make, Zapier y n8n** permiten integrar IA en procesos automatizados sin necesidad de programar desde cero.

### Marcos de trabajo para agentes

| Marco de trabajo | Ideal para |
|------------------|------------|
| LangChain | Aplicaciones generales con LLMs |
| CrewAI | Sistemas multiagente |
| Haystack | Sistemas RAG |
| Dify | Prototipado visual |

### Ejemplos prácticos

Los agentes están transformando: investigación académica, soporte técnico, análisis de redes sociales, desarrollo de software y gestión de proyectos.

## Glosario del bloque

| Término | Definición |
|---------|------------|
| **Agente** | Sistema que percibe, razona y actúa para lograr un objetivo |
| **MCP** | Protocolo estándar para conectar LLMs con herramientas |
| **RAG** | Arquitectura que combina búsqueda + generación de texto |
| **ReAct** | Patrón que alterna razonamiento y acción |
| **Embedding** | Representación vectorial de texto para búsqueda semántica |
| **LLM** | Modelo de lenguaje grande, cerebro del agente |
| **Tool** | Función externa que un agente puede ejecutar |
| **Chunk** | Fragmento de documento usado en RAG |
| **Multiagente** | Sistema con múltiples agentes especializados |
| **Persona en el circuito** | Supervisión humana en decisiones críticas |
