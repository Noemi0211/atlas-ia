## Resumen del bloque

En este bloque hemos explorado cómo la IA está transformando la programación, desde asistentes en el IDE hasta agentes autónomos.

### Lección 1 — Introducción
La programación asistida por IA automatiza tareas como generación, revisión, pruebas y depuración. Quien desarrolla pasa de escribir código a dirigir herramientas que lo generan.

### Lección 2 — Copilot y Cursor
Copilot (extensión) y Cursor (IDE) integran IA en el editor. Copilot es ideal para autocompletado; Cursor ofrece edición multiarchivo y agente autónomo en el IDE.

### Lección 3 — Claude Code y asistentes conversacionales
Claude Code trabaja desde la terminal con acceso completo al proyecto. ChatGPT y Gemini son excelentes para explorar soluciones y depurar. El flujo híbrido combinando varias herramientas es el más eficaz.

### Lección 4 — Agentes autónomos
Devin, Factory y OpenHands representan la siguiente evolución: agentes que planifican, implementan y despliegan código. Aún limitados para tareas complejas, marcan la dirección del futuro.

### Lección 5 — Buenas prácticas
La IA es excelente para la revisión de código, las pruebas y la depuración. Las claves son: ser específico, iterar, verificar siempre y combinar herramientas.

## Glosario del bloque

| Término | Definición |
|---------|------------|
| **Autocompletado** | Sugerencia de código en tiempo real mientras se escribe |
| **Contexto** | Información del proyecto que la IA usa para generar mejores sugerencias |
| **Refactorización** | Mejora de la estructura del código sin cambiar su comportamiento |
| **Revisión de código** | Revisión sistemática del código para detectar errores y mejoras |
| **Agente autónomo** | Sistema que completa tareas de programación de principio a fin |
| **TDD** | Desarrollo guiado por pruebas: escribir las pruebas antes que el código |
| **Código repetitivo** | Fragmentos de código necesarios para configurar proyectos |
