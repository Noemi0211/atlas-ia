## How to use the calculator

1. **Describe your task**: What do you need the AI to do?
2. **Choose the role**: What perspective do you want it to adopt?
3. **Select the format**: How do you want the response?
4. **Add constraints**: Tone, length, audience
5. **Copy the prompt**: The generated prompt is ready to use

## Tips for better results

### Be specific in the task
"Write an email" is vague. "Write a follow-up email to a customer who has not bought in 3 months" is specific.

### The right role
If you are not sure about the role, think about which professional would do that task best. A lawyer? A teacher? A journalist? A chef?

### Format according to the medium
- **Email**: Subject + body + closing
- **Article**: Title + introduction + body + conclusion
- **Analysis**: Data + interpretation + recommendation
- **Code**: Explanation + code + usage examples

## Combination with other techniques

The calculator gives you a base prompt. You can improve it by combining it with advanced techniques:

### Adding Chain-of-Thought
```
[Generated prompt] + "Think step by step before answering"
```

### Adding examples (few-shot)
```
[Generated prompt] + "Here is an example of the format I want: [example]"
```

### Adding iteration
```
[Generated prompt] + "If something is not clear, ask me before answering"
```
