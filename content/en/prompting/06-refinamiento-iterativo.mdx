## The first prompt is almost never the best

Even prompt engineering experts rarely get it right on the first try. The key is to **iterate**: test, evaluate, adjust and repeat.

## The refinement cycle

```
Write prompt → Test → Evaluate result → Identify improvement → Adjust prompt → Repeat
```

## Step 1: Write an initial prompt

Do not aim for perfection. Write something that works as a starting point.

**Initial prompt:**
```
Give me tips to improve my productivity
```

**Typical result:** Generic tips you have heard a thousand times before.

## Step 2: Identify what is missing

Ask yourself:
- Was it too vague? → Add specificity
- Was context missing? → Add your situation
- Was the format not useful? → Specify the format
- Too long? → Simplify

**Identified problem:** The prompt is too vague. It does not specify my situation or the format.

## Step 3: Adjust and test again

**Improved prompt:**
```
I am a freelance developer who works from home. Tell me 5 productivity techniques specific to my situation. For each technique, include: name, how to apply it and expected benefit. In table format.
```

**Result:** Much more useful and applicable.

## Step 4: Refine further

If it is still not perfect, keep iterating:

**Final prompt:**
```
I am a freelance developer who tends to get distracted by social media. I work 8 hours a day from home. I need proven productivity techniques for:

1. Starting the day with focus (first hour)
2. Staying concentrated during 2-hour blocks
3. Managing post-lunch mental fatigue

For each technique: name, concrete steps, time needed and how to measure results.
```

## Specific refinement techniques

### 1. Adding context progressively
```
Prompt 1: "Write a sales email"
Prompt 2: "Write a sales email for project management software"
Prompt 3: "Write a sales email for project management software aimed at Spanish SMEs, highlighting time savings"
```

### 2. Asking the AI for criticism
Ask the AI to evaluate its own response or your prompt:
```
How could this prompt be improved to get a more specific result? Give me 3 concrete suggestions.
```

### 3. Using the result as a new prompt
Take the AI's response and use it as the basis for a new iteration:
```
Take the text you just generated and make it 40% shorter, keeping the key points.
```

### 4. Asking before answering
```
Before answering, ask me questions to better understand what I need. Then respond based on my answers.
```

## Complete refinement example

**Iteration 1:**
```
Create an AI learning plan
```
→ Too generic

**Iteration 2:**
```
I am an entrepreneur with no technical experience. I want to learn AI to apply it to my e-commerce business. Create a 3-month plan.
```
→ Better, but still lacking detail

**Iteration 3:**
```
I am a fashion e-commerce entrepreneur with no technical experience. I want a 3-month AI learning plan, 5 hours/week. Goals:
- Month 1: Understand what AI can do for my business
- Month 2: Try AI tools for e-commerce
- Month 3: Implement at least 1 AI automation
For each month: resources, practical exercises and success metrics.
```
→ Specific, measurable, actionable

## Refinement checklist

Before considering a prompt "finished", verify:

- [ ] Does it have a clear role?
- [ ] Is the context sufficient?
- [ ] Is the task specific?
- [ ] Is the output format defined?
- [ ] Are there useful constraints?
- [ ] Is the tone appropriate?
- [ ] Is the length correct?
- [ ] Does it need examples (few-shot)?
