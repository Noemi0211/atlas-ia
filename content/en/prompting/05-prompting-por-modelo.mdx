## Not all models respond the same way

Each AI model has its own "personality", strengths and limitations. The same prompt can produce very different results in ChatGPT, Claude or Gemini.

## ChatGPT (OpenAI)

**Personality:** Versatile, direct, generalist.

### Works best with:
- Clear, direct instructions
- Step-by-step tasks
- Structured format

### Effective example:
```
You are a research assistant. Analyse these sales figures for the last quarter and generate a 3-section executive report: summary, trends and recommendations. Use a professional tone.
```

### Avoid:
- Very open (vague) instructions
- Asking it to "be creative" without direction

## Claude (Anthropic)

**Personality:** Analytical, nuanced, careful.

### Works best with:
- Questions that require nuance
- Deep document analysis
- Tasks that need precision

### Effective example:
```
Analyse this 20-page document and extract the 5 main arguments for and against the proposal. For each argument, provide textual evidence from the document and rate its strength from 1 to 5.
```

### Avoid:
- Overly direct instructions (Claude is more reflective)
- Very short prompts without context

### Key differences:
Claude tends to be more cautious and nuanced. If you need longer, more detailed responses, give it more space in the prompt.

## Gemini (Google)

**Personality:** Concise, factual, integrated with Google.

### Works best with:
- Factual, up-to-date questions
- Analysis of massive documents
- Integration with Google Workspace

### Effective example:
```
Based on current 2026 trends, tell me what the 3 most important innovations in generative AI are. Include sources and dates.
```

### Avoid:
- Questions that require subjective opinion (Gemini is more factual)
- Long instructions without structure

## Style comparison

| Aspect | ChatGPT | Claude | Gemini |
|---------|---------|--------|--------|
| Response style | Direct, versatile | Nuanced, deep | Concise, factual |
| Ideal length | Medium | Long | Short-medium |
| Tone | Neutral-professional | Careful-formal | Direct-informative |
| Creativity | High | Medium | Low-medium |
| Structure | Likes to follow formats | Prefers flowing text | Responds with lists |

## How to adapt your prompts

### For ChatGPT
```
[Clear instruction] → [Specific format] → [Optional example]
```

### For Claude
```
[Detailed context] → [Nuanced question] → [Request for analysis]
```

### For Gemini
```
[Factual question] → [Response format] → [Request for sources]
```

## Practical example: The same request in 3 models

**Task:** Explain quantum computing to a beginner

**For ChatGPT:**
```
You are a science communicator. Explain quantum computing to someone who knows nothing about the topic. Use 3 real-world analogies and keep it under 200 words.
```

**For Claude:**
```
I need to explain quantum computing to my 70-year-old grandmother who has never heard of it. I want the explanation to be clear, use everyday analogies, highlight why it matters without frightening her, and end with a sentence that invites curiosity.
```

**For Gemini:**
```
Explain quantum computing in simple terms. Give me 3 key points and 1 analogy. Minimum technical jargon. Maximum length: 150 words.
```

<Callout type="tip">
The best strategy is not to learn to use a single model, but to know which one works best for each task and adapt your prompt accordingly.
</Callout>
