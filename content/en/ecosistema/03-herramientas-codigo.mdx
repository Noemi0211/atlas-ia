## AI is revolutionising programming

If you program, AI can be your best ally. Not to replace you, but to **multiply your productivity**. Imagine having an assistant that knows millions of lines of code and can help you in real time.

## The main tools

### GitHub Copilot

**The pioneer of AI in code.**

Copilot was the first widely adopted AI tool for programming:

- **Smart autocomplete**: Suggests code as you type
- **Built-in chat**: Ask questions directly in the editor
- **Multi-language**: Python, JavaScript, TypeScript, Java, and many more
- **Native integration**: Works in VS Code, JetBrains, Neovim

**Ideal for**: Programmers who want quick suggestions without changing their workflow.

**Price**: $10/month individual, $19/month business.

### Cursor

**The editor with native AI.**

Cursor is a VS Code powered by AI at its core:

- **Composer**: Changes across multiple files at once
- **Contextual chat**: The AI understands your entire project
- **Agent Mode**: Automated complex tasks
- **Smart editing**: Modifies existing code with natural instructions
- **Based on VS Code**: Compatible with existing extensions

**Ideal for**: Developers who want a deeper and more integrated AI.

**Price**: Free limited, $20/month Pro.

### Claude / ChatGPT

**General-purpose assistants for code.**

Chatbots are also excellent for programming:

- **Explanations**: Understands existing code
- **Debugging**: Helps find errors
- **Generation**: Creates code from scratch
- **Learning**: Teaches programming concepts

**Ideal for**: Learning, explanations and one-off tasks.

## Which one to choose?

### If you already use VS Code and want something simple
**Copilot**. It integrates in minutes and does not change your workflow.

### If you want the best AI experience for code
**Cursor**. Native integration makes a big difference in large projects.

### If you need explanations or learning
**Claude or ChatGPT**. To understand code, debug specific problems or learn.

### If you are starting to program
**ChatGPT or Claude**. They are easier to use and help you learn.

<Callout type="tip">
Do not compare tools against each other. Many programmers use Copilot for autocomplete, Cursor for large projects, and Claude for explanations. They complement each other.
</Callout>

## Common use cases

### Learning
- "Explain what this function does"
- "Why does my code not work?"
- "Teach me to use React"

### Development
- Autocomplete of repetitive code
- Boilerplate generation
- Refactoring of existing code

### Debugging
- "Why do I get this error?"
- "Find the bug in this function"
- "Suggest a solution"

### Documentation
- Generates README, comments and documentation
- Explains complex code
- Creates usage examples

## The future of programming with AI

AI is not going to replace programmers. It is going to **change how they program**:

- Less repetitive code, more architecture
- Less manual debugging, more design
- Less memorisation, more problem-solving
- Programmers will be more productive, not obsolete

<Callout type="warning">
AI is a powerful tool, but it does not replace the fundamentals. Keep learning the basics of programming. AI makes you faster, but you need to know where you are going.
</Callout>
