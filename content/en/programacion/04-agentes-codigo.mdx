## The next frontier

If Copilot and Cursor assist the programmer, autonomous coding agents aim to take their place. These tools can receive a high-level task and complete it end to end: planning, writing code, testing, debugging and deploying.

<Callout type="info">
Coding agents do not replace the developer, but they change their role: from writing code to specifying requirements and reviewing results. It is like moving from doing a task to directing a team that carries it out.
</Callout>

## Devin (Cognition)

### The first AI software engineer

Devin was introduced in 2024 as the first AI agent capable of completing software projects from start to finish.

### Capabilities

- **Planning:** breaks a task down into steps
- **Navigation:** explores repositories, reads documentation
- **Code writing:** implements across multiple files
- **Execution:** runs code, detects errors, fixes them
- **Deployment:** publishes complete applications
- **Learning:** researches technologies it does not know

### Limitations

- Very complex or ambiguous tasks still fail
- Long execution times (minutes to hours)
- High cost per task
- Depends on the clarity of the instructions

## Factory (formerly Factory AI)

### Approach

Factory focuses on automating development tasks within the team's workflow. It does not aim to replace the developer, but to act as one more member of the team.

### Capabilities

- **Automated code review:** reviews PRs and suggests improvements
- **Issue management:** triage and resolution of simple bugs
- **Documentation:** keeps documentation up to date
- **Continuous refactoring:** progressively improves the codebase

## OpenHands (formerly OpenDevin)

### Open source

OpenHands is the open-source alternative to Devin. You can run it locally and customize it.

### Advantages

- **Free and transparent:** no cost, open source
- **Customizable:** you can modify its behavior
- **Local:** data never leaves your machine
- **Active community:** constant improvements and contributions

<Callout type="tip">
OpenHands is ideal for experimenting with coding agents without financial commitment. You can try it locally and understand how they work before investing in commercial tools.
</Callout>

## What can they do today?

### Tasks that work well

- Creating simple CRUD applications
- Setting up projects from scratch
- Writing unit tests
- Refactoring code with clear patterns
- Migrating between library versions
- Fixing errors with clear error messages

### Tasks that still fail

- Projects with ambiguous requirements
- Systems with many complex dependencies
- Tasks that require human judgment
- Code with critical security implications

<Callout type="warning">
Never deploy code generated by an autonomous agent without fully reviewing it. Agents can introduce security vulnerabilities, violate privacy practices or have unintended side effects.
</Callout>

## The future of programming

### Predictable changes

1. **From code to specification:** you will describe what to do, not how to do it
2. **Review as a key skill:** evaluating code will matter more than writing it
3. **Specialization in prompting:** the best programmers will be the best at communicating requirements
4. **Total integration:** agents that interact with the entire DevOps ecosystem

### What does not change

- Critical thinking and creativity
- Understanding of the fundamentals
- The ability to design architectures
- Ethics and professional responsibility
