## Block summary

In this block we have explored how AI is transforming programming, from IDE assistants to autonomous agents.

### Lesson 1 — Introduction
AI-assisted programming automates tasks such as generation, review, testing and debugging. The developer moves from writing code to directing the tools that generate it.

### Lesson 2 — Copilot and Cursor
Copilot (extension) and Cursor (IDE) integrate AI into the editor. Copilot is ideal for autocomplete; Cursor offers multi-file editing and an autonomous agent in the IDE.

### Lesson 3 — Claude Code and conversational assistants
Claude Code works from the terminal with full access to the project. ChatGPT and Gemini are excellent for exploring solutions and debugging. The hybrid flow combining several tools is the most effective.

### Lesson 4 — Autonomous agents
Devin, Factory and OpenHands represent the next evolution: agents that plan, implement and deploy code. Still limited for complex tasks, they point the way to the future.

### Lesson 5 — Best practices
AI is excellent for code review, testing and debugging. The keys are: be specific, iterate, always verify and combine tools.

## Block glossary

| Term | Definition |
|---------|------------|
| **Autocomplete** | Real-time code suggestion while typing |
| **Context** | Project information that AI uses to generate better suggestions |
| **Refactoring** | Improving the structure of code without changing its behaviour |
| **Code review** | Systematic review of code to detect errors and improvements |
| **Autonomous agent** | System that completes programming tasks from start to finish |
| **TDD** | Test-driven development: writing the tests before the code |
| **Boilerplate code** | Code fragments needed to set up projects |

## Next steps

- **Install:** set up Copilot or Cursor in your usual editor
- **Try:** use a conversational assistant to debug a real error
- **Automate:** generate tests for an existing project with AI
- **Experiment:** try OpenHands locally to understand autonomous agents
- **Compare:** use the same request in ChatGPT, Claude and Gemini and compare results
