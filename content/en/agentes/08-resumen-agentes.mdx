## Block summary

We have explored the fascinating world of **AI agents and automation**. Let us review the essentials:

### Fundamental concepts

An AI agent is a system that **perceives, reasons and acts** to achieve a goal. It combines an LLM as its brain with tools, memory and autonomy.

### Types of agents

| Type | Key | Main use |
|------|-----|----------|
| Reactive | No memory | Simple, immediate tasks |
| With memory | Persistent state | Assistants and chatbots |
| Autonomous | Multi-step planning | Complex automation |
| Multi-agent | Specialised roles | Enterprise projects |

### MCP (Model Context Protocol)

The open standard for connecting agents with external tools. Client ↔ Server, with automatic discovery and security through isolation.

### Advanced RAG

Architecture that combines **information retrieval** with text generation. Key techniques: semantic chunking, multi-query retrieval, result re-ranking and contextual RAG.

### Workflow automation

Platforms such as **Make, Zapier and n8n** allow you to integrate AI into automated processes without programming from scratch.

### Agent frameworks

| Framework | Ideal for |
|-----------|-----------|
| LangChain | General applications with LLMs |
| CrewAI | Multi-agent systems |
| Haystack | RAG systems |
| Dify | Visual prototyping |

### Practical examples

Agents are transforming: academic research, technical support, social media analysis, software development and project management.

## Block glossary

| Term | Definition |
|------|------------|
| **Agent** | System that perceives, reasons and acts to achieve a goal |
| **MCP** | Standard protocol for connecting LLMs with tools |
| **RAG** | Architecture that combines search + text generation |
| **ReAct** | Pattern that alternates reasoning and action |
| **Embedding** | Vector representation of text for semantic search |
| **LLM** | Large language model, the brain of the agent |
| **Tool** | External function that an agent can execute |
| **Chunk** | Document fragment used in RAG |
| **Multi-agent** | System with multiple specialised agents |
| **Human in the loop** | Human supervision in critical decisions |
