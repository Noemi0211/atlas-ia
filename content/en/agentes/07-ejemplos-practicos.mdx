## Agents in action

AI agents are already transforming entire industries. In this lesson we will look at real use cases that illustrate the potential of this technology.

<Callout type="info">
Each example follows the same pattern: a complex goal that an agent breaks down, executes and verifies autonomously.
</Callout>

## Case 1: Academic research assistant

### Problem

A researcher needs to review 50 scientific papers a week to stay up to date. Doing it manually takes hours.

### Agent-based solution

A multi-agent system with:

1. **Searcher agent:** queries academic databases (arXiv, PubMed, Google Scholar)
2. **Extractor agent:** reads each paper and extracts: abstract, methodology, results, limitations
3. **Analyser agent:** identifies trends, contradictions and connections between papers
4. **Writer agent:** generates a personalised weekly report with the most relevant findings

### Result

The researcher receives a 5-page report every Monday with the essentials, saving 10+ hours a week.

## Case 2: Technical support automation

### Problem

A support team receives 200 tickets a day. 60% are repetitive questions that could be resolved automatically.

### Agent-based solution

1. **Classifier:** categorises the ticket (technical, billing, account)
2. **RAG searcher:** searches the knowledge base for relevant articles
3. **Generator:** drafts a personalised response based on the documentation
4. **Verifier:** confirms that the response resolves the question
5. **Escalator:** if it cannot resolve it, it passes it to a human with all the context

### Result

45% of tickets are resolved without human intervention. Average response time: 2 minutes vs 4 hours.

<Callout type="tip">
The key to success in technical support with agents is not replacing the human, but giving them more context and time for complex cases.
</Callout>

## Case 3: Sentiment analysis on social media

### Problem

A brand needs to monitor 10,000 daily mentions on social media to detect reputation crises.

### Agent-based solution

1. **Collector:** captures mentions from multiple sources (Twitter, Instagram, Reddit, forums)
2. **Analyser:** classifies each mention by sentiment (positive, negative, neutral) and intensity
3. **Anomaly detector:** identifies peaks of negative sentiment and groups them by topic
4. **Alert generator:** if it detects a possible crisis, it sends an urgent report to the communications team

### Result

Crises are detected in minutes instead of hours. The team can respond before the problem escalates.

## Case 4: Code assistant for development

### Problem

A development team wants to review and maintain a legacy codebase of 500,000 lines.

### Agent-based solution

1. **Analyser agent:** maps the code architecture and documents dependencies
2. **Reviewer agent:** identifies code smells, vulnerabilities and technical debt
3. **Refactorer agent:** suggests and applies code improvements (with human approval)
4. **Documenter agent:** generates automatic documentation of functions and modules
5. **Testing agent:** creates unit tests for the uncovered code

### Result

40% reduction in errors. The team spends 30% less time on maintenance.

## Case 5: Automated project management

### Problem

A project manager coordinates 5 teams and 15 projects simultaneously. Manual tracking is not feasible.

### Agent-based solution

1. **Progress monitor:** reviews the status of each task in Jira/Asana daily
2. **Risk detector:** identifies blocked tasks, unmet dependencies and schedule deviations
3. **Report generator:** produces personalised status reports for stakeholders
4. **Meeting coordinator:** automatically schedules the necessary meetings based on the project status

### Result

The project manager recovers 8 hours a week, which they devote to strategic decisions instead of operational tasks.

## Common patterns

These cases share patterns that you can replicate:

1. **Observe** a data source (tickets, papers, mentions, code)
2. **Analyse** using an LLM with specialised context
3. **Decide** what action to take based on rules or criteria
4. **Act** by executing a tool (send email, create ticket, generate report)
5. **Learn** from the result to improve future decisions

<Callout type="info">
The most effective pattern is the "human in the loop": the agent does the heavy lifting, but critical decisions always go through a person.
</Callout>

## How to design your own agent

1. **Identify** a process that is time-consuming and repetitive
2. **Define** the goal in measurable terms
3. **Divide** the process into steps that an agent can execute
4. **List** the tools it will need (APIs, databases)
5. **Prototype** with a framework (LangChain, CrewAI)
6. **Test** with real cases and measure results
7. **Iterate** based on feedback
