## The prompt laboratory

The Prompt Environment is your personal workshop for designing and testing instructions for AI models. Here you can experiment with different configurations and see how each one affects the result.

<Callout type="info">
A well-designed prompt is the difference between a generic answer and an exceptional one. The environment lets you find the perfect combination for each need.
</Callout>

## Components of the environment

### Available selectors

- **Role:** defines the personality of the assistant (teacher, expert, creative, technical, coach)
- **Format:** structure of the answer (article, list, table, tutorial, FAQ, summary)
- **Tone:** communication style (formal, informal, fun, inspiring, neutral)
- **Audience:** who it is aimed at (beginner, intermediate, advanced, children, professional)
- **Length:** desired length (short, medium, long)

## How to use the environment

### Step 1: Define the goal

Before writing, ask yourself: what do I want to achieve? A good prompt is born from a clear goal.

**Bad example:** "Tell me about AI"
**Good example:** "I want a practical guide for teachers who are starting to use AI in the classroom"

### Step 2: Select the configuration

Each selector changes the result:

- **Role = teacher + Tone = formal** → academic and structured answer
- **Role = creative + Tone = fun** → original and entertaining answer
- **Audience = children + Format = tutorial** → simple answer with visual steps

### Step 3: Write and experiment

Write your prompt and test it with different combinations. Observe how it changes:

- The structure of the answer
- The vocabulary used
- The depth of the content
- The examples it includes

### Step 4: Refine

Based on the results, adjust the original prompt. Add more context, restrictions or examples.

## Recommended experiments

### Experiment 1: Same prompt, different role

Prompt: "Explain what fine-tuning is"

Try with role: teacher, technical and creative. Observe how the explanation changes.

### Experiment 2: Same topic, different audience

Prompt: "How transformers work"

Try with audience: beginner, advanced and children.

### Experiment 3: Same content, different format

Prompt: "Benefits of using AI in education"

Try with format: list, table and article.

<Callout type="tip">
Document your experiments. Note which combinations work best for each type of task. You will create your own personalised prompt guide.
</Callout>

## Effective prompt patterns

### Persona pattern

> "Act as [role] and [action]. Consider that your audience is [audience]."

### Template pattern

> "Complete the following outline: [structure]. The topic is [topic]."

### Chain of thought

> "Step by step, explain [topic]. First... then... finally..."

### Few-shot pattern

> "Here is an example: [example]. Now do the same with [new case]."
