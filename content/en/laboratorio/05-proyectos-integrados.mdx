## From tools to projects

You have explored each laboratory tool separately. Now it is time to combine them to solve real problems. Integrated projects prepare you to apply what you have learned in real-world situations.

<Callout type="info">
True mastery of AI is not about using one tool well, but about knowing which tool to use for each problem and how to combine them to get superior results.
</Callout>

## Project 1: Complete educational assistant

### Goal

Create a learning support system that combines several capabilities.

### Laboratory tools

1. **AI Chat:** research the topic and generate base content
2. **Prompt Environment:** design optimised prompts for each educational task
3. **Agent Flow:** build a flow that receives questions and returns contextualised answers
4. **Comparator:** select the best model for each type of educational task
5. **Token Simulator:** estimate costs before scaling the solution

### Workflow

1. Use the AI Chat to explore the educational topic
2. Design prompts in the Prompt Environment for different roles (teacher, tutor, examiner)
3. Build a flow in Agent Flow that chains the answers
4. Compare models to choose the most suitable one
5. Simulate token consumption to plan the usage

## Project 2: Document analyser

### Goal

A system that processes long documents, extracts key information and generates reports.

### Suggested flow

1. **Prompt Environment:** design the extraction prompt (role=analyst, format=report)
2. **Agent Flow:** chain Input → LLM (extract) → LLM (structure) → Output
3. **Token Simulator:** calculate the cost of processing large documents
4. **Comparator:** evaluate which model handles long documents best

## Project 3: AI tools comparison

### Goal

Complete research comparing tools for a specific use case.

### Suggested flow

1. **AI Chat:** research the tools available for your use case
2. **Comparator:** select up to 4 tools and compare them
3. **Prompt Environment:** generate a recommendation report
4. **Token Simulator:** estimate the costs of each option

## Project 4: Content automation

### Goal

A flow that generates, reviews and formats content automatically.

### Example in Agent Flow

```
Input (topic)
  → LLM (generate draft)
  → LLM (review and correct)
  → Tool (format)
  → Output (final content)
```

<Callout type="tip">
Do not try to use every tool in every project. Select the ones that add real value to the goal. A project with 2 well-used tools is better than one with 5 poorly integrated tools.
</Callout>

## Methodology for your projects

### Phase 1: Definition

- What problem does it solve?
- Who will use the solution?
- Which laboratory tools are relevant?

### Phase 2: Prototyping

- Test each component separately
- Adjust prompts and configurations
- Validate partial results

### Phase 3: Integration

- Connect the components
- Test the complete flow
- Identify bottlenecks

### Phase 4: Optimisation

- Refine prompts based on results
- Adjust the order of the nodes
- Optimise token consumption

### Phase 5: Documentation

- Note down the configurations that worked
- Create a usage guide
- Share your learnings

## Final challenge

Design, implement and document an integrated project that:

1. Uses at least 3 laboratory tools
2. Solves a real problem in your field
3. Includes a flow of at least 3 nodes in Agent Flow
4. Documents the design decisions and the results
