## The Atlas IA laboratory

The laboratory is the hands-on space of Atlas IA. Here you do not just learn theory: you experiment, test, compare and create. It is the place where the concepts from the previous blocks come to life through interactive tools.

<Callout type="info">
The laboratory is designed so that you learn by doing. Each tool lets you experiment without risk: try, make mistakes, adjust and try again. That is how you really learn AI.
</Callout>

## Laboratory tools

### AI Chat

Conversational assistant with real-time token streaming. You can ask questions about any AI topic and receive real-time answers. It includes topic suggestions and markdown support.

### Prompt Environment

Create and test prompts with different settings: choose a role, format, tone, audience and length. Watch how the result changes in real time. Ideal for mastering prompt engineering.

### Agent Flow

Visual designer for agent flows. Drag and connect nodes (Input, LLM, RAG, Tool, Output) to build automated workflows. You can reorder them and configure each node.

### Model Comparator

Compare up to 4 tools or models side by side. Filter by category and consult a comparative table with criteria such as price, quality, speed and ideal use cases.

### Token Simulator

Estimate the token consumption of your texts. Choose between 6 models, select the estimation mode (words or characters) and visualise the usage in a contextual bar.

## How to get the most out of the laboratory

### For beginners

Start with the [AI Chat](/laboratorio). Ask basic questions about concepts that were not clear to you in the previous blocks. Then try the Prompt Environment to understand how the same prompt changes depending on the configuration.

### For intermediate students

Use the Model Comparator to understand the differences between tools. Experiment with the Token Simulator to optimise your prompts. Build your first flow in Agent Flow.

### For advanced users

Design complex flows in Agent Flow combining multiple tools. Create projects that integrate several laboratory capabilities. Compare models and document your conclusions.

## General tips

- **Experiment without fear:** all the tools are for trying things out
- **Iterate:** the best results come from testing, adjusting and repeating
- **Combine:** use several laboratory tools in the same project
- **Document:** note down which configurations work best

<Callout type="tip">
The laboratory is updated regularly with new tools and features. Come back from time to time to discover what is new.
</Callout>
