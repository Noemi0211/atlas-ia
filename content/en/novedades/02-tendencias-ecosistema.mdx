## Beyond the models

While language models grab the headlines, the ecosystem around them evolves with equally transformative trends. In 2026 the protagonist is not a new architecture, but **practical application**: agents that act, protocols that connect and a cost that is collapsing.

<Callout type="info">
The model is only one piece of the puzzle. The real revolution lies in how models connect, deploy and are applied in the real world.
</Callout>

## Autonomous agents

The most important trend in the ecosystem: moving from models that answer questions to systems that carry out tasks.

### Evolution

1. **2023:** conversational chatbots
2. **2024:** simple agents with tools
3. **2025:** multi-step agents with planning
4. **2026:** coordinated multi-agent systems in production

### Real adoption

Agentic AI has moved from demonstration to production:

- 79% of companies state that they already use AI agents in real business scenarios
- Gartner projects that 40% of enterprise applications will include agents by the end of 2026 (up from less than 5% in 2025)
- MCP tool calls from ChatGPT grew 98x during 2026

### Featured platforms

- **Claude Code:** terminal agent that reads, writes and runs code
- **Cursor:** editor with built-in coding agents
- **OpenHands:** open-source alternative to coding assistants
- **CrewAI and LangGraph:** frameworks for orchestrating agent teams

## Protocols: MCP, A2A and ACP

### MCP (Model Context Protocol)

Anthropic introduced MCP in 2024 as an open standard for connecting models with tools. The July 2026 specification marked its largest revision since launch:

- **"The USB-C of AI":** a single protocol to connect any tool or data source
- **Mass adoption:** around 250 million weekly SDK downloads, and more than 10,000 public servers
- **Open governance:** since December 2025 the protocol is managed by the Linux Foundation, within the Agentic AI Foundation
- **Stateless core:** the 2026-07-28 revision removed persistent connections, allowing servers to be deployed behind standard load balancers, serverless and at scale

### News in the 2026-07-28 specification

- **MCP Apps:** official extension that lets tools return interactive interfaces inside the chat
- **MCP Tasks:** extension for long-running tasks asynchronously, without keeping the connection open
- **Elicitation (MRTR):** servers can ask the user for confirmation before executing a destructive or costly action
- **Formal deprecation policy:** changes are announced at least 12 months in advance

### A2A (Agent-to-Agent)

Google promotes A2A, the protocol for communication between agents:

- It allows agents from different vendors to discover each other, delegate tasks and collaborate
- It reached version 1.0 in 2026 and moved under the same foundation as MCP

### How they relate

- **MCP** connects the agent with the tools (vertical connection)
- **A2A** connects agents with each other (horizontal coordination)

<Callout type="tip">
MCP is set to be what HTTP was for the web: a standard that enables interoperability. If you work with AI agents, MCP is one of the most important technologies you can learn.
</Callout>

### The security challenge

With mass adoption come risks. In the early months of 2026 more than 30 MCP-related CVEs were filed, including a remote code execution vulnerability with a score of 9.6 out of 10:

- **Tool poisoning:** a malicious tool description can trick the model into leaking data, without the user ever seeing it
- **Scarcely deployed OAuth:** in 2026 only 8.5% of remote servers implement the mandatory OAuth 2.1 authentication standard
- Governance and monitoring are now as important as integration

## AI in the browser and on-device

Running models in the browser and on local devices is democratising access:

- **WebLLM:** runs models such as Llama and Gemma in the browser
- **Transformers.js:** transformer inference directly in JavaScript
- **Chrome Built-in AI:** native AI APIs in Chrome

### Small language models (SLM)

Small language models, optimised to run locally, have drastically cut inference costs and enable private AI on devices:

- No server required
- Total privacy (local data)
- No network latency
- Works offline

## Open source and democratisation

The open-source AI ecosystem has matured enormously:

- **Models:** Muse, Qwen 3.8, DeepSeek V4, GLM-5, Mistral, Llama
- **Frameworks:** LangChain, Haystack, DSPy, LlamaIndex
- **Infrastructure:** vLLM, Ollama, TGI, llama.cpp
- **Datasets:** Hugging Face leads with millions of datasets

<Callout type="info">
In 2026 the prediction that open models would match proprietary ones on most tasks came true. Muse, Qwen and DeepSeek offer frontier quality at a fraction of the cost.
</Callout>

## Other relevant trends

**Generative Video AI**
Veo 3.1, Sora 2, Kling 3.0 and Runway Gen-4.5 generate video with synchronised audio, consistent characters and near-cinematic quality.

**Reasoning and chains of thought**
Models that make their reasoning process explicit, such as the GPT-6 family or Claude 5, with deep reasoning modes.

**Mass personalisation**
Fine-tuning and RAG make it possible to create specialised assistants for each user or organisation.

**Agent security and governance**
The maturation of MCP and its large-scale adoption put security and governance at the centre of the agentic ecosystem.
